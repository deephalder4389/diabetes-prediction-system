
# Diabetes Prediction System

A machine learning-based web application for predicting
diabetes using patient health parameters.

## Technologies Used
- Python
- Scikit-learn
- Pandas and NumPy
- Flask
- HTML and CSS

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

Final Selected Algorithm: Random Forest Classifier

## Project Features
- Data preprocessing
- Exploratory Data Analysis
- Feature importance analysis
- Hyperparameter tuning
- Model evaluation using Accuracy, Precision,
  Recall and F1-Score
- Diabetes prediction using a Flask web application

## Dataset
Pima Indians Diabetes Dataset
